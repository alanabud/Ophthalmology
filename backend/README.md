# Ophthalmology Enterprise Platform Backend

Phase 1 foundation for a modular FastAPI backend serving a multi-tenant ophthalmology clinic platform.

The current deliverable includes:

- application bootstrap and environment-based configuration
- async PostgreSQL and Redis connectivity scaffolding
- authentication, RBAC, tenant, clinic, and audit module foundations
- structured logging, request correlation, and health/readiness endpoints
- Celery worker bootstrap and initial test coverage
